# 過去データ保管庫

ここは、販売数字や公開レビューなど、あとから比較・再確認するための元データをためる場所です。
普段の判断や提案は `CMO/`、全員が確認する方針は `Shared/`、元データはこのフォルダに置きます。

## 保存場所

| フォルダ | 保存するもの | 保存しないもの |
|---|---|---|
| `sales/` | 週次・月次の集計済み販売数字 | 注文ごとの明細、氏名、住所、注文番号 |
| `reviews/` | 個人情報を除いた公開レビュー、収集日が分かる資料 | 投稿者名、注文情報、非公開の問い合わせ |

現在の継続表:

- `sales/月次販売実績.csv`: 月ごとの確定値・途中経過
- `sales/週次販売実績.csv`: 毎週月曜から日曜までの実績
- `reviews/主力商品レビュー50件_2026-08-29.md`: 主力商品の分析に使った公開レビュー

## ファイル名の決め方

- 日付を含める資料: `内容_YYYY-MM-DD.md`
- 継続して追記する表: 内容が分かる固定名にする（例: `週次販売実績.csv`）
- 同じ内容の最新版を別名で増やさず、継続表へ行を追加する

## 安全ルール

- 顧客の氏名、住所、電話番号、メール、注文番号は保存しない
- 楽天などのログイン情報、画面写真、取り出したままの注文データは保存しない
- 商品ページや広告を変更した記録は、実施日・内容・結果だけを匿名で残す
