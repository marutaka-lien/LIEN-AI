# 販売施策の効果記録

商品ページ、価格、広告などを変更したときに、変更前後の数字を残す場所です。

## ファイル

- `主力商品ページ改善_記録.csv` … 主力インナー（商品管理番号 1000000115）の変更前後の比較表（本命の記録）
- `raw/` … RMSからダウンロードした元CSV（全商品ぶん・加工前）。比較表の数字の出典。
  期間が分かる名前を付ける（例: `商品ページ分析_全商品_2026-08-17_2026-08-23.csv`）。

## ルール

- 1つの期間に大きな変更を複数重ねない
- 変更日、変更内容、値引き、広告、在庫切れの有無を必ず残す
- 顧客情報や注文ごとの明細は保存しない
- 結果の判断と次の提案は `CMO/` に記録する
