# 課題: RMS同期の失敗を画面で分かるようにする

起票日: 2026-09-09（フライデー）
担当: グラム（LIENmanager）
優先度: 中（発送まわりが落ち着いたら。プロジェクトL/Fの後でよい）
段階: 未着手。着手時は Gate 1（原因整理・直し方の提案）から。

## 背景（2026-09-09 の不具合）

楽天RMS APIのライセンスキーが期限切れになり、9/9 11:48(JST)以降 RMS API が 401 を返して
注文の自動取り込みが全停止した。ところが**アプリは失敗を画面に出さず**、発送エントリー画面は
「対象0件／CSVに出力できる行がありません」と表示していたため、"注文が少ない日" にしか見えなかった。
マスターが「新規注文が入らない」「発送完了報告CSVで対象者が見つからない」と気づいて発覚。

- `GET /api/orders` … `fetchPendingOrders()` の失敗を `console.error` のみで握りつぶし（画面に出ない）。
- `POST /api/rms/shipping-report/sync` … `errors[]` に詰めて返すが、パネルは
  `toast.warning("最新化しましたが、RMS側で${n}件のエラーがありました")` と件数だけ。中身（401/認証エラー）を出さない。

## やること（案）

1. **同期失敗を画面に明示する**。
   - 発送エントリーの「最新化」: `errors` に認証エラー（`RmsAuthError` / status 401,403）が含まれる場合は
     `toast.error` で「RMSと通信できません（APIキーの期限切れの可能性）。管理者に連絡してください」と具体的に出す。
     「対象0件」の静かな表示と混同させない。
   - ダッシュボード（プロジェクトF C案の右ゾーン）に「最終同期：○時○分／**失敗**」を常時表示。
     成功時刻だけでなく、直近の同期が失敗しているかどうかが一目で分かるように。
   - `GET /api/orders` のバックグラウンド同期失敗も、次の一覧取得時にバナー等で拾えるようにする
     （握りつぶしをやめる。ただし一覧表示自体は止めない）。
2. **ライセンスキーの期限切れを事前に警告する**。
   - RMS の `license.expiryDate.get`（R-Loginで「利用中」を確認済み）を使い、
     有効期限まで残り N 日を切ったらダッシュボードに警告。日次で1回チェックする程度でよい。
   - 認証情報は `.env`（`RMS_SERVICE_SECRET` / `RMS_LICENSE_KEY`）。API パス・レスポンス形は Gate 1 で調査。

## 完了条件（目安）

- 認証エラー時、「最新化」で原因が分かる文言が出る。
- ダッシュボードで「直近同期が失敗している」ことが分かる。
- （2 を入れる場合）期限が近いと警告が出る。
- 既存テストは悪化なし。

## 注意

- 個人情報はチャット・ログ・コミットに出さない。
- `.env` は日本語コメント入り UTF-8。PowerShell スクリプトでの一括書き換えは禁止（2026-09-09 に破損事故）。編集は手作業で。
