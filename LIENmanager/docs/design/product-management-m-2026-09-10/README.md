# プロジェクトM 商品管理 UIモック

作成日: 2026-09-10  
位置づけ: 商品登録APIを利用した商品管理機能の、実装前確認用モック。API接続・本番データ変更は行わない。

## 確認方法

`preview.html` をブラウザで開く。

## 確認できる画面と操作

- 商品一覧: 商品カードを押すと商品詳細が開く。
- 新商品登録: 「既存商品を複製」「ゼロから登録」の入口と9段階の登録手順。
- 予約状況: カレンダー／リストの表示切替。カレンダーの日付選択。
- 商品詳細: 売れ行き、在庫、次回予約の概要。

## 前提

- 商品写真はLIEN提供素材を使用。
- 売上・在庫・購入率・予約内容はすべて架空データ。
- タブは `商品一覧 / 新商品登録 / 予約状況` の3つ。登録ひな形は初期版には含めない。
- 楽天への登録・更新・予約送信は行わない。

## 次に確認すること

1. 商品一覧で最初に見たい数字は適切か。
2. 商品詳細のタブと情報量は適切か。
3. カレンダーの日付を押した際に見たい情報が揃っているか。
4. 新商品登録の9段階が実際の業務順と合うか。
5. 「投稿予約」が楽天の商品登録・更新予約だけか、SNS投稿予約も含むか。
