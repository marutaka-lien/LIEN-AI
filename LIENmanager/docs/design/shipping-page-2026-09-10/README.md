# 発送ページ集約 ― ラフモック（2026-09-10）

`docs/SHIPPING_PAGE_CONSOLIDATION_BRIEF_2026-09-10.md` を、フライデーが手組みした**構造確認用の静的モック**。
Claude Design に渡す前に「並び・情報量・フロー順」をマスターが見るためのもの。視覚の作り込みはこれから。

## ファイル

- **`mock.html`** ― ブラウザでそのまま開ける（外部読み込みなし）。1440px想定・ダーク固定。
  - 右上のボタンで `通常 / loading / empty / error / 成功表示` を切り替えて各状態を確認。
  - 上部タブで「作業メニュー」「注文者情報一覧」を切り替え。
  - データはすべて架空（氏名・住所・注文番号はダミー）。

## このモックで表現していること

- サイドバーは3項目（ダッシュボード / 発送エントリー / レビュー）＝「注文一覧」を削除済み。
- 作業メニュー＝業務フロー順の縦1本:
  1. 確認待ち通知 → 2. 未処理＋対象者CSV作成 → （GoQ）→ 3. 発送完了報告CSV → 4. 作業中 → 5. 処理済み → 6. 一時保存
- 一時保存の行に「未処理へ戻す」「一時保存から外す」の2アクション。
- 注文者情報一覧＝全ステータス表＋検索＋行操作（一時保存にする／選択CSV作成）。
