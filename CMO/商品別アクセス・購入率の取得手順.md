# 商品別アクセス・購入率の取得手順

更新日: 2026-08-29（担当: フライデーが実画面を確認して作成）
用途: 主力商品ページ改善の「変更前・変更後」を比べるための、**商品1つ分**の閲覧数と購入率。
記録先: `BusinessData/experiments/主力商品ページ改善_記録.csv`

## 結論（フライデーのRMS実画面確認より）

商品ごとの閲覧数・購入率は **RMSで取れる**。画面は
**「アクセス・流入分析 → 商品ページ」（商品ページ分析）**。
週次販売数字（店舗全体）とは別の画面なので、混同しない。

## RMSでの操作

1. 楽天RMSへログインする。
2. RMSメインメニューの **「データ分析」** を開く。
3. 左メニューの **「アクセス・流入分析 → 商品ページ」** を開く。
4. **期間選択**: 「日次」を選び、前週の月曜〜日曜（改善前の記録は同じ曜日構成の2週間ぶんを1週ずつ）にする。
   ※日次でも期間の範囲指定ができる。月次でも可。
5. **キーワード**: 「商品管理番号」を選び、`1000000115` を入力して検索する（主力ノースリーブインナー）。
6. **端末**: 「すべて」。
7. 表の上のチェックで **「売上の公式」「集客」** にチェックを入れる。
8. 主力商品の行から、次の数字を `主力商品ページ改善_記録.csv` の各列へ書き写す。

| CSVの列 | RMS画面の項目 | 補足 |
|---|---|---|
| 商品ページ閲覧数 | アクセス人数 | その商品ページに来た人数。転換率の分母 |
| 購入件数 | 売上件数 | ＝総購入件数 |
| 購入率 | 転換率 | 画面が計算済み（売上件数 ÷ アクセス人数） |
| 販売個数 | 売上個数 | 売れた点数 |
| 値引き・ポイント | （手入力） | その週にクーポン・ポイント施策があったか（有/無と内容） |
| 広告 | （手入力） | その週にRPP等の広告を回したか（有/無） |
| 在庫切れ | （手入力） | 主要な色・サイズが欠品していた期間があるか |

9. 参考として、同じ画面の **新規購入件数 / リピート購入件数**、**滞在時間 / 直帰数** も控えておくと、
   ページ改善の効き方を見るときに使える（CSVには列が無いので備考欄かメモへ）。
10. まとめて取る場合は、行の **「商品単位」CSV** または上部の **「全商品CSV」** をダウンロードして、
    主力商品の行を確認する（初回は画面表示と一致するか見る）。

## この画面で取れる項目（一覧）

- 売上の公式: 売上 / 売上件数 / 売上個数 / アクセス人数 / 転換率 / 客単価
- 集客: ユニークユーザー数 / 総購入件数 / 新規購入件数 / リピート購入件数 / 商品リピート件数 /
  商品リピート率 / 未購入アクセス人数
- お気に入り: レビュー投稿数 / レビュー総合評価（点）/ 総レビュー数
- 回遊: 滞在時間（秒）/ 直帰数 / 離脱数 / 離脱率
- 在庫: 登録ユーザー数 / 総ユーザー数

## 注意

- 「転換率・客単価」（店舗カルテ）は**店舗全体**の数字。商品1つ分の改善評価には使わない。
- 大型セール・価格変更・在庫切れが重なった週は、CSVの「備考」に明記して別扱いにする。
- 数字はRMSの表示をそのまま写す。推測で埋めない。画面の項目名が変わっていたらフライデーへ伝える。
- 個別注文データ（顧客情報を含む）はこの記録に使わない。
