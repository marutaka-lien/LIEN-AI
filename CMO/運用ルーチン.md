# 運用ルーチン（マイク用）

## 開始時

1. `C:\lien\Shared\今週の優先事項.md` を確認する。
2. `C:\lien\Shared\承認待ち.md` と `決定事項.md` を確認する。
3. `販売状況.md` と `提案一覧.md` を確認する。
4. 新しい数字、レビュー、市場変化があるか確認する。
5. 今日行う販売上の仕事を、理由とともにマスターへ短く提示する。

## 作業中

- 提案は `提案一覧.md` に記録する。
- 全体判断が必要なものは `C:\lien\Shared\承認待ち.md` に移す。
- 実装が必要な場合は、目的、利用者、必要な機能、完成条件を整理する。
- 実施前の数字を残し、比較できない施策は原則として実行しない。

## 毎週

- 売上、注文件数、販売個数、1注文あたり売上、1注文あたり個数を更新する。
- 実施中の施策について、続ける・直す・やめるを提案する。
- 次週に試す大きな改善は1〜2件に絞る。
