# 週次販売数字の取得手順

更新日: 2026-08-29  
担当: マスター（取得・記入） / マイク（集計確認） / フライデー（様式確認）

## 目的

毎週、同じ画面・同じ期間・同じ定義で5つの数字を取り、週ごとの変化を比較できるようにする。

## 集計期間

- 1週間は **月曜日から日曜日まで** とする。
- 毎週月曜日に、直前に完了した1週間を取得する。
- 初回は **2026-08-17（月）から2026-08-23（日）まで** を取得する。
- 途中の週は記録しない。月をまたぐ週も月曜日から日曜日のまま集計する。

## RMSでの操作

1. 楽天RMSへログインする。
2. RMSメインメニューの **「データ分析」** を開く。
3. **「4 売上分析」** を開く。
4. **「店舗売上」** を開く。
5. 期間指定を開き、開始日を前週の月曜日、終了日を前週の日曜日にする。
6. 端末・デバイスの選択がある場合は **「すべて」** を選ぶ。
7. 表示または検索ボタンを押し、指定期間の集計結果を表示する。
8. 画面に表示された次の3項目を、そのまま `CMO/販売状況.md` の空欄へコピーする。
   RMS画面の表記と保存先の欄名は次のように対応する。
   - 「売上」 → 売上 / 売上円
   - 「売上件数」 → 注文件数
   - 「売上個数」 → 販売個数
9. `1注文あたり売上` は「売上 ÷ 売上件数」、`1注文あたり個数` は「売上個数 ÷ 売上件数」で計算する。
10. 5項目と期間を見直し、更新日を記入する。
11. 確認後、同じ1週間分を `BusinessData/sales/週次販売実績.csv` に1行追加する。

`CMO/販売状況.md` は現在の確認用、`BusinessData/sales/週次販売実績.csv` は過去との比較用とする。
同じ週を二重に追加しない。

## 取り出し方法

- 当面は **画面から数字をコピーして貼り付ける**。
- 個別注文のCSVは顧客情報を含むため、この週次集計には使用しない。
- 店舗売上画面に集計結果だけのCSV出力がある場合も、初回は画面表示と一致することを確認してから利用する。

## 売上の扱い

この手順では、店舗売上画面に表示された売上を加工せず記録する。

- 消費税: **税込**
- 送料: **含めない**
- クーポン: **値引き後の売上**
- 計上時点: 注文日を基準とした店舗売上画面の集計値

楽天では画面によって「売上」の定義が異なる。上記は店舗カルテと同じ計測方法を使う
店舗売上画面の前提として記録する。初回取得時に画面内の説明と一致するか、フライデーが確認する。

参考:

- 楽天市場「R-Karteで売上データを分析する」: https://www.rakuten.co.jp/ec/environment/service/analysis/
- 店舗売上画面への経路の参考: https://note.com/gogo_buppan/n/n17777a91a5c9
- 店舗カルテと同じ売上定義の参考: https://captainec.jp/rakuten/spin_off/realtime_date

## 貼り付ける形式

```text
期間: 2026-08-17〜2026-08-23
売上: ______円
売上件数: ______件
売上個数: ______個
```

マスターは上の3項目だけをマイクへ渡せばよい。平均の2項目はマイクが計算する。

## 初回だけ確認すること

- メニュー名が実画面でも「データ分析 → 4 売上分析 → 店舗売上」になっているか。
- 画面内の売上定義が「税込・送料を含めない・クーポン値引き後」と一致するか。
- 売上件数と売上個数の両方が同じ画面に表示されるか。

表示が異なる場合は数字を推測せず、画面名と表示項目だけをフライデーへ伝える。

## 様式確認結果（2026-08-29 フライデー）

3つの資料（`Shared/数字の定義.md` ／ 本手順 ／ `CMO/販売状況.md`）と、
2つの表（`BusinessData/sales/週次販売実績.csv` ／ `月次販売実績.csv`）を照合した。

確認できたこと:

- 集計期間「月曜〜日曜の完了した1週間」は3資料で一致。**この形で固定してよい**。
- 記録する列の順序（期間 → 売上 → 注文件数 → 販売個数 → 1注文あたり売上 → 1注文あたり個数 → 取得日）は
  `販売状況.md` の週次表と週次CSVで一致。**この順序で固定してよい**（CSVは期間を開始日・終了日の2列に分け、末尾に備考を持つ）。
- 初回だけ実画面で見る3点（メニュー経路・売上の定義・件数と個数の表示）は、マスターのRMS画面をフライデーが確認する。未実施。

そろえた点（2026-08-29 マスター承認。数字そのものは変えていない）:

1. 「売上」の列名を統一。両CSVとも `売上円`（中身は税込・送料含めない・クーポン値引き後。定義は `Shared/数字の定義.md` と `BusinessData/README.md`）。
2. 楽天RMS画面の表記と保存先の欄名の対応を、本手順「RMSでの操作」手順8に追記した。
3. 月次CSV `BusinessData/sales/月次販売実績.csv` の先頭に `種別` 列を追加し、`通算` 行と `月次` 行を区別した。

マスターの初回入力はこのまま進めてよい。
