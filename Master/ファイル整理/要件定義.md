## 4. 命名規則

| 種類 | 形式 | 例 |
|---|---|---|
| 商品フォルダ | `番号_商品名_品番` | `032_モック_5805` |
| その他フォルダ | `番号_名前` | `06_従業員`、`01_麻里子さん` |
| 時系列が必要なフォルダ | `番号_名前_日付` | `01_e商人講演_2024-09-20` |

- 区切りは `_`（Windowsは `/` 不可）
- 名前は日本語
- 日付は `YYYY-MM-DD`
- **番号は通し番号。一度付けたら振り直さない**（欠番は欠番のまま）。商品は3桁、その他は2桁
- **品番が複数ある商品は代表品番のみ**をフォルダ名に入れ、他の品番は品番台帳に書く
- 品番のハイフンは除く（RMS表記 `66-55969` → `6655969`）
- **ルールを適用するのはフォルダだけ**。ファイル名は変えない（カメラ連番等が2万件以上あるため）

## 5. 品番台帳（Claudeの精度の要）

- 場所: `Master/ファイル整理/品番台帳.csv`（確定前は `品番台帳_下書き.csv`）
- 列: 通し番号 / 代表品番 / 商品名(短縮) / 別品番 / 楽天商品管理番号 / RMS品番表記 / Dフォルダ / RMS商品名 / 状態 / 備考
- 商品フォルダの名前は **台帳から機械的に作る**。台帳にない商品フォルダは作らない
- 新商品が出たら、まず台帳に1行足す → 番号確定 → フォルダ作成
- 品番で検索すれば、通し番号・正式名・両層のフォルダに辿り着ける状態を保つ

## 6. 運用ルール（以降の実行手順）

1. **受信箱**：新しいファイルは `業務\90_受信箱\` に入れる。フライデーが本ルールで仕分ける
2. **移動**：一度に全部動かさない。フォルダ単位で「移動 → ショートカット・Excelリンク・LIENmanagerのパス確認」を繰り返す
3. **削除**：してよい。ただし**実行前に対象一覧と「消すメリット／デメリット」を提示し、マスターの承認を得る**
4. **迷ったら**：`99_保管庫\` に入れて、台帳か本書に判断を追記する
5. **ルール変更**：本書を更新してから実行する（本書が唯一の正）
