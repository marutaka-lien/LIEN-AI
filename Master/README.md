# Master フォルダ（高橋幸大／AIコーディネーター）

マスター本人が全体を見渡すための管制塔。
「どんなプロジェクトがあって、どれが進行中で、それぞれの進捗・たまっているタスク・
将来の発展・進め方は何か」を1か所にまとめる。

## ファイル

- `プロジェクト一覧.md` … 全プロジェクトの一覧表（状態・進捗・積みタスク・将来像・進め方）。**ここを常に最新にする。**

## 使い方

- 週のはじめ／方針が動いたとき／タスクが増減したときに `プロジェクト一覧.md` を更新する。
- 詳細は各担当フォルダ（`CEO/` フライデー、`CMO/` マイク、`Gram/`・`LIENmanager/` グラム、`BusinessData/` 元データ）にあり、
  ここはあくまで「見出しと現在地」。二重管理しない。
- 経営責任者（グランドマスター）に見せる・聞くことは `GrandMaster/` にためる。

更新はフライデーが行う（マスターの指示・報告を反映）。
