# Money 初回投稿案（2026-09-15）

方向性: LIEN（日本製・綿100%・接触冷感 ハイネックノースリーブインナーを主力に扱う小規模アパレルEC）の実務を、Claude Code（AIエージェント）でどこまで自動化できたかをそのまま実況する。X（またはnoteの無料記事）に投稿する想定の下書き。マスターがそのまま使う／編集する／別の切り口にする、いずれもOK。事実（既に完了した内容）のみを使い、数字は記録済みのものだけ。

投稿ツール自体（X・note）への実際の投稿はClaudeにはできないため、コピペして使えるようテキストのみ用意する。

---

## 案1: 自己紹介・シリーズ開始の投稿

```
小さなアパレル通販(LIEN)をやっています。
最近、日々の実務をClaude Code（AIエージェント）に任せる実験を始めました。

・受注処理
・発送業務
・商品登録

をどこまでAIに任せられるか、うまくいった話も失敗した話もそのまま書いていきます。
第一弾は「毎日1件ずつ手でコピペしていた発送番号入力」をなくした話から。
```

## 案2: 具体的な自動化エピソード（プロジェクトLの実話）

```
うちの発送作業、こんな手間がかかっていました。

クリックポストで発行された追跡番号を、楽天RMSの「お荷物伝票番号」欄へ
1件ずつ手でコピペ。多い日で1時間。

→ クリックポストが吐き出すCSVを読み込んで、宛先情報で注文を自動照合し、
RMSへ一括アップロードできるCSVを作るところまで、Claude Codeに実装してもらいました。

今は数分で終わります。
```

## 案3: 失敗談を含めた投稿（信頼感を出す用）

```
最初は「RMSへAPIで直接書き戻す」自動化を試しましたが、これはうまくいかず断念。

結局、「クリックポストのCSVを、RMSアップロード用のCSVに変換する」という
一段階遠回りなやり方に落ち着きました。

AIに完璧な自動化を求めるより、人間の最後のひと押し（RMSへのアップロード操作）
を残す設計にしたことが、結果的にうまくいった理由だと思っています。
```

## 追記（2026-09-17）: 案1をXへ投稿→文字数オーバーで失敗

案1(自己紹介・シリーズ開始)の原文はXの文字数制限（全角文字は2文字分に換算される）を超えて投稿できなかった。
noteへは案1の原文のまま投稿済み。X用に短縮した版を用意する（実測: 全角換算245字、上限280字以内）。

```
小さなアパレル通販(LIEN)を営んでいます。
最近、受注・発送・商品登録の実務をAIエージェント(Claude Code)に任せる実験を開始。

うまくいった話も失敗談もそのまま発信していきます。
第一弾は「手作業のコピペをなくした発送番号入力」の話をnoteに投稿しました。
```

note記事へのリンクを末尾に足す余地あり（実測で約35字分の余裕）。マスターが実際のnote URLを付けて投稿する。

## 使い方の提案

- まず案1で開始を宣言し、以降は案2・案3のような「1トピック＝1エピソード」の投稿を続ける。
- ネタは尽きない想定: 発送CSVの文字化け修正、運用ダッシュボードの刷新、商品一覧のRMS実データ接続、在庫のリアルタイム化など、既に完了している改善が他にも複数ある（`Master/プロジェクト一覧.md` F・G・M参照）。
- 反応（いいね・コメント・フォロワー増）が付き始めたら、それをまとめた有料note（500〜800円、実践ログ＋指示テンプレ集）の企画に進む。
