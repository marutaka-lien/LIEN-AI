# Money 投稿ライブラリ

「ある貧乏大学生がAIでアプリ開発」の投稿案と画像を、1投稿につき1フォルダで管理する。

## フォルダの見方

```text
Money/content/
└─ YYYY-MM-DD_連番_短い題名/
   ├─ post.md       投稿案・確認事項・投稿後の数字
   └─ banner.png    noteへアップロードする見出し画像
```

マスターは各フォルダの `post.md` を確認し、同じ場所の `banner.png` をダウンロードして使用する。

## 運用ルール

1. 実際に起きたことだけを書く。
2. 売上、期間、使用したAIなどの数字は公開前に人が確認する。
3. AIが作った推測を本人の体験として書かない。
4. 公開前の投稿は `下書き`、公開後は `公開済み` と記録する。
5. 公開後は表示数、反応、フォロー、noteへの流入、売上を同じ `post.md` に追記する。
6. 見出し画像は原則1.91:1で、重要な人物や物を中央付近に置く。

### 記事の質を上げる3原則（2026-09-17追加・軽量版）

マイクの調査(`CMO/`)を踏まえ、記事の質を上げる原則だけを採用する。
タイトル案を複数出してマスターが選ぶ、バナー案を複数作るといった承認の往復は、
実行数を減らすため今は導入しない。

7. **タイトルは「誰の・何が・どう変わったか」を具体的に書く**。実測できる数字（時間・件数など）が
   あれば入れる。ただし確認できる事実のみ使う。例:「AIで効率化しました」ではなく
   「毎日1時間かかっていた発送番号のコピペが、数分で終わるようになるまで」。
8. **冒頭3行で結論を見せる**（逆三角形構成）。①以前の困りごと ②現在の結果 ③この記事で分かること、の順。
9. **見出しで話の流れが分かるようにする**。基本構成: 何に困っていたか→以前の作業→AIに何を頼んだか
   →実際に作った仕組み→どう変わったか→うまくいかなかった点→他社が真似する場合の注意点→次回。
