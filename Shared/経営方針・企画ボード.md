# 経営方針・企画ボード

最終更新: 2026-08-29（フライデー）

## これは何 / 使い方

グランドマスター（高橋大樹・経営責任者）との会議で出た **方針・企画・アイデア** を、
ひと目で分かる形にまとめておく場所。会議の前後にここを見れば「いま何を目指していて、
何が動いていて、何が未決か」が分かる状態にする。

- **方針** … 大きな方向。めったに変えない。
- **進行中の企画** … いま動かしている具体策。担当と状態つき。
- **アイデア置き場** … やるかどうか未決。検討・確認待ち。
- **会議メモ** … グランドマスター会議で決まったこと・宿題を日付順に。

書き込みルール: 全員に影響する変更はフライデーがここへ反映する（担当ファイルの分担は
`決定事項.md` 2026-08-28 のとおり）。決着したアイデアは「進行中の企画」へ移すか、
`決定事項.md` へ記録して却下理由を残す。

## いまの方針（2026-08-29 時点）

1. **運営の型を先に固める**。調査 → 提案 → 承認 → 実行 → 効果確認 を毎週回せるようにする。
   感覚でなく数字と購入者の声で判断する。
2. **主力商品（ハイネックノースリーブインナー / 1000000115）に集中**。
   販売を増やす前に「実際に残る金額」と「買われている理由」を先に把握する。
3. **比較できない施策はやらない**。変更前の数字を必ず残してから変える。
4. **情報は GitHub リポジトリと `Shared/` を共通の置き場にする**。個人の記憶に閉じない。
5. **本番変更・費用・外部公開・重要な方針はマスター（必要に応じグランドマスター）承認後**。
6. 今週やらないこと: 新しいAIエージェントの追加 / 根拠のない大規模なページ変更 / 効果を比較できない販売施策。
