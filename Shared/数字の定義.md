# 毎週確認する数字の定義

| 数字 | 意味 | 計算方法 |
|---|---|---|
| 売上 | 対象期間に販売した金額 | 楽天の集計値を使用 |
| 注文件数 | 対象期間に受けた注文の数 | 楽天の売上件数を使用 |
| 販売個数 | 対象期間に売れた商品の合計個数 | 楽天の売上個数を使用 |
| 1注文あたり売上 | 1件の注文で平均いくら購入されたか | 売上 ÷ 注文件数 |
| 1注文あたり個数 | 1件の注文で平均何個購入されたか | 販売個数 ÷ 注文件数 |
| 商品別売上 | 商品ごとの売上 | 商品別の販売金額を集計 |
| 商品別利益 | 商品ごとに実際に残る金額 | 売上－仕入れ－楽天費用－送料－梱包費－広告費 |
| レビュー評価 | 商品への満足度 | 評価平均と件数を併記 |

数字の集計期間、税込・税抜、送料の扱いを途中で変えない。変更する場合は、変更日と理由を
`決定事項.md` に記録する。

## 週次集計の統一ルール

- 期間: 月曜日から日曜日までの完了した1週間
- 取得画面: 売上・売上件数は楽天RMS「データ分析 → 売上分析 → 店舗売上」、
  販売個数は同「売上分析 → 商品別売上」の総計（2画面方式。2026-08-29）
- 売上: 店舗売上画面の表示値をそのまま使用
- 消費税: 税込
- 送料: 含めない
- クーポン: 値引き後
- のし・ラッピング代: 含む（店舗売上画面の売上の説明どおり）
- 端末・デバイス: すべて
- 取得方法: 当面は集計値を画面からコピーし、個別注文CSVは使わない

商品別売上画面から取ることが判明したため2画面方式にした）。以後は画面の売上の説明が変わっていないかを
マスターが目視し、変わっていればマスター判断後に定義を修正する。
