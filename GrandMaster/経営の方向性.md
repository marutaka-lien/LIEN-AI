## いまの方針（2026-08-29 時点）

1. **運営の型を先に固める**。調査 → 提案 → 承認 → 実行 → 効果確認 を毎週回せるようにする。感覚でなく数字と購入者の声で判断する。
2. **主力商品（ハイネックノースリーブインナー / 1000000115）に集中**。販売を増やす前に「実際に残る金額」と「買われている理由」を先に把握する。
3. **比較できない施策はやらない**。変更前の数字を必ず残してから変える。
4. **情報は GitHub リポジトリと `Shared/` を共通の置き場にする**。個人の記憶に閉じない。
5. **本番変更・費用・外部公開・重要な方針はマスター（必要に応じグランドマスター）承認後**。
6. 当面やらないこと: 新しいAIエージェントの追加 / 根拠のない大規模なページ変更 / 効果を比較できない販売施策。
