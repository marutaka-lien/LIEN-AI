# GrandMaster フォルダ（高橋大樹／経営責任者）

経営責任者（グランドマスター）に関わることをためる場所。
グランドマスターは普段この作業スペースをノータッチで、実務はマスターの承認で進む。
だからここは「経営判断が要る点」「会議で決まったこと」「事業の向き」を、
後日まとめて見せる・確認するための置き場にする。

## ファイル

- `経営の方向性.md` … いまの事業の向きと大きな方針。会議前後に読む1枚。
- `確認事項.md` … グランドマスターに聞かないと進めない個別事項（Q1, Q2, …）。回答が入ったら印を付けて各タスクへ反映。
- `会議メモ.md` … 会議で決まったこと・宿題を日付順に。

## 使い方

- 新しく確認したいことが出たら `確認事項.md` に Q番号で追記する。
- 会議をしたら `会議メモ.md` に記録し、決定を `Shared/決定事項.md` と `Master/プロジェクト一覧.md` にも反映する。
- 更新はフライデーが行う。
